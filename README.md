# OADP レースペース二系統入力・再計算構造 v1.3

この仕様では、レースペースを次の3方式で扱います。

1. AIテキストから読み込む
2. 使用者が手動入力する
3. AI値を初期値として、使用者が一部だけ上書きする

手動変更時も、単なる「スロー・平均・ハイ」のラベル変更ではなく、
区間速度、ペース強度、前列圧、先頭差、隊列の伸び、位置変化率を
min/mode/maxのレンジで変更します。

変更後は、その馬だけでなく全馬の競り・追走・外圧・進路・消耗を再計算し、
Stage1、Stage2、全着順確率、印候補まで更新します。

AI原値は消さず、手動変更前後の差分を保存します。
