# OADP シナリオ分離型レースシミュレーター（試作版）

JRA出馬表テキストを入力し、OADPの「S1/S2/S3は着順違いではなく4角到達構造の違い」という原則に沿って、異なる入力世界を作り、同一のモンテカルロエンジンで走らせます。

## 起動
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## 実装済み
- JRAプレーンテキストの基本パース
- FACTから基礎DERIVED/ESTIMATEを生成
- ハナ取得確率、先手参加率
- 前列圧発生/被害、序盤位置不発
- 差し接続、残存エネルギー、進路実現、失速率
- S1/S2/S3別モンテカルロ
- 4角順位平均/SD、勝率、複勝率
- シナリオ独立監査
- CSV/JSON出力

## 制限
OADPで係数が完全固定されていない部分は暫定式です。人気・オッズは物理計算とシナリオ発生確率に使用しません。

## v0.4.0 イベント駆動型への全面改修

従来の「各馬の共通能力点へシナリオ別係数を掛ける」方式を廃止し、条件付きイベント型Monte Carloへ変更しました。

### 主な変更
- 能力を単一総合点ではなく、START / CRUISE / POSITION / PRESSURE / CORNER / RECOVERY / STRAIGHT / VMAX の局所容量へ分離
- 各試行で発馬成功・失敗、先行参加、ハナ主張、相手の抵抗、前列圧、内包まれ、外回し、息入れ、3角進出、再加速を抽選
- 前列圧を全馬共通係数ではなく、競合馬と主導馬の相互作用として付与
- 消耗を「要求負荷が局所容量を超えた量」の二乗項を含む非線形更新へ変更
- 4角出口で位置・速度・残存エネルギーを確定してから、直線能力を後入れ
- S3を S3-Fa（横広がり前列圧）、S3-Fb（前列圧不発・前残り）、S3-L（後方差し接続）へ内部分岐
- 区間イベント集計とS3内部分岐発生率を画面・JSONへ追加
- 監査を「4角首位馬が同じか」ではなく、区間イベント過程差と4角順位相関で判定

### 重要
同じ馬がS1/S2/S3で4角首位候補になること自体はNGにしていません。
首位へ至る過程、圧力、残存エネルギー、3角進出、S3内部構造が分離しているかを監査します。


## v0.4.1 4角位置状態修正

v0.4.0では、STARTで作成した順位配列を後続区間でも使い回しており、序盤の主導馬交代・競り・包まれ・3角進出が4角位置へ十分反映されない不具合がありました。

### 修正
- 順位配列の使い回しを廃止し、連続位置 `position state` を区間ごとに更新
- 主導馬交代、控え、競り、包まれ、外回し、3角進出を位置へ直接反映
- MID_CRUISEの前列判定をSTART時順位ではなく、その時点の位置から再計算
- S3-Fbの「競るはずの馬が控え、別の前受け馬が主導」を実際の位置分岐として実装
- S3-Lの後方接続を3角移動量と4角速度へ直接反映
- 4角順位平均だけでなく、中央値・最頻位置帯・位置帯別確率を出力
- 監査へ「4角並び完全一致」「4角平均順位差」を追加
